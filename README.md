# RetailPro
Proyecto de análisis de datos orientado al estudio del desempeño comercial de una empresa minorista ficticia.
## Objetivo
Analizar ventas, clientes, productos y sucursales para identificar oportunidades de mejora comercial y apoyar la toma de decisiones basada en datos.
## Herramientas utilizadas
- SQL Server
- SQL Server Management Studio (SSMS)
- GitHub
- ChatGPT como asistente para documentación y validación
## Tablas principales
- Clientes
- Productos
- Categorías
- Sucursales
- Territorios
- Ventas

## Análisis realizados
- Ventas por mes
- Ticket promedio
- Productos más vendidos
- Productos con mayor facturación
- Clientes con mayor gasto
- Comparación de desempeño mensual

## Ejecución
1. Crear la base de datos RetailPro.
2. Ejecutar el script de creación de tablas.
3. Cargar los datos.
4. Ejecutar las consultas SQL analíticas.
5. Revisar los resultados obtenidos para la generación de insights.
